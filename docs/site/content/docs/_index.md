go-libfossil reads, writes and syncs Fossil repositories in Go, without cgo. It ships as a Go module and as the `libfossil` command.

- **[Get started](/docs/get-started/)**: install, a first repository from the command line, the library from Go, and a first sync.
- **[Concepts](/docs/concepts/)**: artifacts, the derived tables, the sync protocol, sub-manifests, sparse cones, horizons and signing.
- **[Guides](/docs/guides/)**: production use, migrating from fossil, embedding the CLI, extension points and testing.
- **[Reference](/docs/reference/)**: the Go API, the command line, settings, and conformance with the drafts.
- **[Examples](/docs/examples/)**: runnable programs in the repository.
