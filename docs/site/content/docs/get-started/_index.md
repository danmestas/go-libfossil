Install the `libfossil` command, make a first repository from the command line, embed the library in a Go program, and sync with another repository.

- [Install](/docs/get-started/install/): the command, the Go module, and the SQLite driver.
- [Quickstart: the CLI](/docs/get-started/quickstart/): create a repository, commit, and read it back with stock `fossil`.
- [Embed in Go](/docs/get-started/embed-in-go/): create, commit, open and read history from Go.
- [First sync](/docs/get-started/first-sync/): serve a repository, clone it, pull and push.
